1 · The raw machine

AntihydraRawTM.lean lines 30–116 · mirrored in Dossier1RawTM.lean

Layer 1 is deliberately boring: it is the part a skeptical reviewer must trust, so every definition is as small as it can be.

Types and the transition table

defState, Dir, Instr
inductive State | A | B | C | D | E | F     -- six control states
inductive Dir   | L | R                     -- head directions
structure Instr where
  next  : State    -- state after the step
  write : Bool     -- symbol written under the head (false=0, true=1)
  dir   : Dir      -- which way the head moves afterwards

An Instr is one cell of the machine's program. The tape alphabet is Bool: false is the blank 0, true is 1.

definstr : State → Bool → Option Instr

The full Antihydra program, transcribed from the standard code 1RB1RA_0LC1LE_1LD1LC_1LA0LB_1LF1RE_---0RA. none is the undefined transition — the machine has nowhere to go, which is the definition of halting.

A,0 ↦ (B, 1, R)    A,1 ↦ (A, 1, R)     -- A runs right over 1s
B,0 ↦ (C, 0, L)    B,1 ↦ (E, 1, L)
C,0 ↦ (D, 1, L)    C,1 ↦ (C, 1, L)     -- C runs left over 1s
D,0 ↦ (A, 1, L)    D,1 ↦ (B, 0, L)
E,0 ↦ (F, 1, L)    E,1 ↦ (E, 1, R)     -- E runs right over 1s
F,0 ↦ none  ⟵ THE HALT                 F,1 ↦ (A, 0, R)

Three self-loops (A,1 · C,1 · E,1) rewrite 1 over 1 — the tape is literally unchanged while they run. That one observation powers the entire sweep layer (§3).

Tape algebra — four lemmas, no more

defmove · writeAt · Config
move (h : Int) : Dir → Int          -- L ↦ h−1, R ↦ h+1
writeAt (tape : Int → Bool) (pos : Int) (v : Bool) : Int → Bool
  := fun x => if x = pos then v else tape x
structure Config where
  state : State      -- current control state
  head  : Int        -- head position on the two-way-infinite tape
  tape  : Int → Bool -- the whole tape, as a total function
variablemeaning
tapetotal function ℤ → Bool; “infinite tape” with no edge cases
posthe single cell being overwritten
xthe probe point: writeAt answers for any cell

Everything the development ever does to a tape is a stack of writeAts. Four lemmas are the complete toolkit:

writeAt_same      : writeAt t p v p = v                    -- read the written cell
writeAt_other  (h : x ≠ p) : writeAt t p v x = t x         -- reads elsewhere untouched
writeAt_self   (h : t p = v) : writeAt t p v = t           -- writing what's there: no-op
writeAt_overwrite : writeAt (writeAt t p v) p w = writeAt t p w  -- last write wins

writeAt_self is the secret hero: the three self-loop transitions write 1 over 1, so their steps provably do not change the tape function at all.

One step, then n steps

defstep · stepN · RawHalts · Reaches
step (c : Config) : Option Config :=
  match instr c.state (c.tape c.head) with   -- read the cell under the head
  | none     => none                          -- undefined transition: HALT
  | some ins => some ⟨ ins.next,
                       move c.head ins.dir,
                       writeAt c.tape c.head ins.write ⟩

stepN : Nat → Config → Option Config          -- n steps; none once halted
  | 0,     c => some c
  | n + 1, c => match step c with
                | none    => none
                | some c' => stepN n c'

RawHalts (c : Config) : Prop := ∃ n, stepN n c = none
Reaches  (c d : Config) : Prop := ∃ n, stepN n c = some d
blankStart : Config := ⟨A, 0, fun _ => false⟩
variablemeaning
c, c', dconfigurations before / after one step / after n steps
insthe instruction looked up for (state, read symbol)
nstep budget; stepN absorbs a halt at any point into none

One composition law, stepN_add : stepN (m+n) c = (stepN m c).bind (stepN n), proved by induction on m, is what lets long runs be glued out of proven segments — it is used dozens of times in §4.

2 · Halt localization

AntihydraRawTM.lean lines 99–218

Goal of the layer: shrink “the machine halts” from anything could happen down to one specific two-cell tape pattern was reachable.

The only exit

theoremstep_eq_none_iff
step c = none  ↔  c.state = F ∧ c.tape c.head = false

Proof. Case-split on the 6 states × 2 symbols; eleven cases produce some _, one produces none. Twelve simp calls. Nothing clever — by design.

theoreminto_F_only_from_E0
step c = some c'  →  c'.state = F  →
    c.state = E                          -- predecessor was in E
  ∧ c.tape c.head = false               -- reading a 0
  ∧ c'.head = c.head − 1                -- E,0 = (F,1,L): moved left
  ∧ c'.tape = writeAt c.tape c.head true  -- and wrote a 1

Proof. Same 12-way case split: only the E,0 row produces successor state F. So any halt is preceded by state E reading a 0.

theoremstepN_none_last · stepN_some_pred
stepN_none_last : stepN n c = none →
  ∃ k < n, ∃ d, stepN k c = some d ∧ step d = none
stepN_some_pred : stepN (k+1) c = some d →
  ∃ e, stepN k c = some e ∧ step e = some d
variablemeaning
nlength of the run that halted
k, dindex and configuration of the last live configuration
ethe immediate predecessor of a run's endpoint

Proof. Both walk the run by induction on n / k: peel one step, recurse on the tail, shift indices with omega. Together they let any halting run be rewound to the exact moment before death.

The probe contract

theoremhalt_requires_e_probe_00
c.state ≠ F → RawHalts c →
  ∃ d, Reaches c d ∧ d.state = E
     ∧ d.tape d.head = false            -- E is reading a 0 …
     ∧ d.tape (d.head − 1) = false      -- … and its LEFT neighbour is 0

Proof sketch. Take the halting run (hh), rewind to the last live configuration d0 (stepN_none_last); it satisfies step d0 = none, so by step_eq_none_iff it is F-reading-0. Its predecessor e (stepN_some_pred) entered F, so by into_F_only_from_E0 e was E-reading-0 at head h, and the halting cell F reads is h − 1 — which the E-step did not write (writeAt_other, since h − 1 ≠ h). So the 0 that F dies on was already there when E probed: E read a 0 with a 0 to its left.

10011

the fatal pattern: state E (ring) reading 0, with 0 on the left — the “E-probe of 00”

defEProbeSafenonhalting_of_e_probe_safe
EProbeSafe (c : Config) : Prop :=
  ∀ d, Reaches c d → d.state = E → d.tape d.head = false →
       d.tape (d.head − 1) = true      -- every probed 0 has a 1 on its left

nonhalting_of_e_probe_safe : c.state ≠ F → EProbeSafe c → ¬ RawHalts c
blank_nonhalting_of_e_probe_safe : EProbeSafe blankStart → ¬ RawHalts blankStart

Proof. A halt would produce the 00-probe of the previous card; EProbeSafe says that probe's left cell is 1; contradiction (Bool.noConfusion). This is the interface: everything above layer 2 exists to discharge EProbeSafe blankStart.

3 · Sweeps and the segment algebra

AntihydraRawTM.lean lines 220–441

Sweep lemmas — the atoms

theoremsweep_A · sweep_C · sweep_E
-- E sweeps right across n ones without touching the tape:
sweep_E : c.state = E → (∀ i < n, c.tape (c.head + i) = true) →
          stepN n c = some ⟨E, c.head + n, c.tape⟩   -- SAME tape function
-- sweep_A: identical, state A, rightwards
-- sweep_C: identical, state C, LEFTwards (c.head − i, c.head − n)
variablemeaning
nlength of the block of 1s being crossed
ioffset inside the block (hypothesis quantifier)
honesthe block hypothesis ∀ i < n, tape(head±i) = 1

Proof. Induction on n. Base: zero steps. Step: the self-loop instruction fires (step_E_on_one, built from writeAt_self — writing 1 over 1 leaves tape literally equal), then the induction hypothesis crosses the remaining n−1 ones. Every macro rule's trajectory is a chain of these sweeps plus a bounded number of boundary steps.

Segment safety algebra

defESafeSegcompose / of_strong / of_noE
ESafeSeg (c : Config) (N : Nat) : Prop :=      -- safety for the FIRST N steps
  ∀ k d, k < N → stepN k c = some d → d.state = E →
         d.tape d.head = false → d.tape (d.head − 1) = true

esafe_compose : stepN m c = some c' → ESafeSeg c m → ESafeSeg c' n
              → ESafeSeg c (m + n)             -- glue segments end to end
esafe_of_strong : (every E-configuration reads a 1)   → ESafeSeg c N
esafe_of_noE    : (no configuration is in E at all)   → ESafeSeg c N
variablemeaning
N, m, nsegment lengths; compose splits k into “before m / after m” with stepN_add
k, dan arbitrary moment inside the segment and its configuration

The two discharge lemmas handle 95% of proof obligations: most segments either never visit E, or visit it only on 1s. Only the genuine probes need hand analysis — and §4 shows there are exactly one to two per rule.

The keystone

theoremeprobe_safe_of_segments
(h0 : Inv c0)
(hseg : ∀ c, Inv c → ∃ k > 0, ∃ c', stepN k c = some c'
                              ∧ Inv c' ∧ ESafeSeg c k)
→ EProbeSafe c0
variablemeaning
Invany invariant on configurations (instantiated with OrbitInv in §5)
c0the start (instantiated at the post-startup record)
k, c'each segment's positive length and endpoint

Proof. Strong induction on a bound N: any reachable moment n falls either inside the current safe segment (hsafe answers directly) or beyond it — subtract the segment (stepN_add), land on c' where Inv holds again, recurse. Infinitely many finite safe segments become safety for the whole infinite run. Its sibling eprobe_safe_prefix bolts a finite startup prefix onto the front.

4 · The three rules — certified trajectories

AntihydraRawTM.lean lines 442–1320

Each empirical macro rule became a theorem with two halves: the exact trajectory (step count and output tape, for all block values) and an ESafeSeg certificate covering its own duration. A record is the machine's tape shape at a frontier moment: counter block a, gap, middle block m, gap, block c, head on fresh tape.

hydra_step — 96% of everything

theoremhydra_step
-- anchor p = right end of the m-block; k = length of the c-block
(hs : cfg.state = B) (hh : cfg.head = p + 2 + k)
(tm2 : tape (p−2) = 1) (tm1 : tape (p−1) = 1) (tm0 : tape p = 1)  -- m ≥ 3 top
(tg  : tape (p+1) = 0)                                            -- the gap
(tc  : ∀ i < k, tape (p+2+i) = 1)                                 -- the c-block
(tf  : tape (p+2+k) = 0)                                          -- fresh frontier
→ stepN (2k + 11) cfg
    = some ⟨B, p+3+k, tape[p+1↦1][p−1↦0][p+2+k↦1]⟩                -- next record
  ∧ ESafeSeg cfg (2k + 11)
variablemeaning
panchor: rightmost cell of the middle block
kcurrent c-block length — the trajectory costs exactly 2k+11 steps
tm2…tfthe seven tape preconditions spelling out the record shape near p

Trajectory (each sN a proven single step, sweeps for the unbounded parts): B steps off the frontier → sweep_C left across the c-block (k steps) → 6 boundary steps C→D→B→E→E→E→F eat two cells of the m-block and rebuild the gap → F writes the counter-side repair → sweep_A right across k+2 ones → one final step plants the new frontier 1. Net: (a, m, c) → (a, m−2, c+3), counter untouched.

The probe. Exactly one E-reads-0 moment, at offset 5 of the boundary run, probing cell p — safe because p−1 provably still holds its 1 (hw3m1 in the source). The certificate is assembled with esafe_compose over the seven sub-segments; five discharge with esafe_of_noE.

drop_step — the counter pays

theoremdrop_step
-- fires when m = 2; anchor q = right end of the COUNTER block
preconditions: counter top at q · gap · the 2-block at q+2,q+3 · gap · c-block (k) · frontier
→ stepN (2k + 15) cfg = some ⟨A, q+6+k, …seven writeAt's…⟩  ∧  ESafeSeg cfg (2k+15)

Net effect (a, 2, c) → (a−1, c+3, 2): the counter block shrinks by one cell. Two probes: E reads the gap at q+1 — safe because the counter cell q holds 1 (this is exactly why the abstract rule demands a ≥ 2); and E reads the new frontier — safe because the c-top holds 1. The death of the whole conjecture lives here: with a ≤ 1 there is no counter 1 to certify the first probe.

merge_chain — the counter feeds

theoremmerge_chain
-- fires when m = 1; n = counter length (hn : 1 ≤ n), k = c-block length
→ stepN (2n + 2k + 22) cfg = some ⟨B, p+6+k, …eleven writeAt's…⟩ ∧ ESafeSeg …

Net effect (a, 1, c) → (a+2, c+2, 2). The head crosses the entire counter block (hence the 2n in the cost), extends it by two on the far side, and returns. Both probes are safe; the first precisely because the counter is non-empty (hn). The eleven-deep writeAt tower in the statement is the exact output tape — nothing is approximated.

AState, astep, and the conjecture

defAState · astep · aorbit · SafeOrbitA
structure AState where a m c : Nat        -- counter, middle block, c block

astep : AState → Option AState
  | (a, m, c) => if 3 ≤ m     then some (a, m−2, c+3)          -- hydra
                 else if m = 2 then (if 2 ≤ a then some (a−1, c+3, 2)
                                     else none)                 -- drop — CAN DIE
                 else if m = 1 then some (a+2, c+2, 2)          -- merge
                 else none                                      -- m = 0 — dead

aorbit 0 = some (2, 7, 2)                 -- the post-startup record
aorbit (k+1) = (aorbit k) >>= astep
SafeOrbitA : Prop := ∀ k, aorbit k ≠ none   -- ⟵ THE CONJECTURE
Death set (proved exact in packages/dossier1): m = 0 ∨ (m = 2 ∧ a ≤ 1). Every value pattern whose absence from the orbit is the Antihydra conjecture.

Realizes — the tape grammar, cell by cell

defRealizes (a, m, c) cfg
1 ≤ a ∧ 1 ≤ m ∧ 1 ≤ c ∧ cfg.state = B ∧ ∃ p : Int,
  (∀ x < p−a+1,        tape x = 0)   -- ① blank forever leftwards
∧ (∀ i < a,  tape (p−i)     = 1)     -- ② the counter block, ending at p
∧            tape (p+1)     = 0      -- ③ single-0 gap
∧ (∀ i < m,  tape (p+2+i)   = 1)     -- ④ the middle block
∧            tape (p+2+m)   = 0      -- ⑤ single-0 gap
∧ (∀ i < c,  tape (p+3+m+i) = 1)     -- ⑥ the c block
∧ (∀ x ≥ p+3+m+c, tape x    = 0)     -- ⑦ blank forever rightwards
∧ cfg.head = p+3+m+c                 -- ⑧ head exactly on the frontier

Eight conjuncts pin the entire infinite tape: every cell is determined by (a, m, c) and the anchor p. Conjunct ② with 1 ≤ a is why the grammar cannot follow a drop at a = 1 — the origin of the “heads ≤ 1” strengthening documented in the bridge.

transport_drop  : Realizes (a+2, 2, c) → … Realizes (a+1, c+3, 2) …
transport_merge : Realizes (a, 1, c)   → … Realizes (a+2, c+2, 2) …

orbit_segment (hso : SafeOrbitA) : OrbitInv cfg →
  ∃ k > 0, ∃ cfg', stepN k cfg = some cfg' ∧ OrbitInv cfg' ∧ ESafeSeg cfg k
  -- where OrbitInv cfg := ∃ n s, aorbit n = some s ∧ Realizes s cfg

Each transport applies its §4 rule at the anchor the grammar provides and re-derives all eight conjuncts for the successor shape — pure writeAt_other/omega bookkeeping. The dispatcher case-splits astep: alive cases hand off to the matching transport; dead cases contradict SafeOrbitA. The startup's safety uses checkSafe, an executable boolean checker proven sound (esafe_of_checkSafe) — 62 steps checked by rfl.

7 · What sits on top (and what never leaks down)
